This repository contains all implementations for **Unit 1: Foundations & Algorithmic Analysis** from the Data Structures Lab Manual (2026).

Unit 1 focuses on:

# 🧪 Experiments Included

---

## 🔹 Experiment 1 – Stack ADT (Design + Use)

* Implemented custom Stack ADT
* Operations: `push()`, `pop()`, `peek()`, `isEmpty()`, `size()`
* Meaningful use: String reversal

**Complexity**

* Push → O(1)
* Pop → O(1)

---

## 🔹 Experiment 2 – Complexity Drill

Implemented loop structures:

* Single Loop → O(n)
* Nested Loop → O(n²)
* Triangular Loop → O(n²)
* Halving Loop → O(log n)

Also discussed:

* Best Case
* Average Case
* Worst Case
* Linear Search vs Binary Search

---

## 🔹 Experiment 3 – Recursive Factorial

* Recursive implementation
* Call stack trace for factorial(4)

**Time Complexity:** O(n)
**Space Complexity:** O(n)

---

## 🔹 Experiment 4 – Fibonacci (Naive vs Memoized)

* Naive recursive version
* Memoized (Dynamic Programming) version
* Call counter comparison

**Naive Complexity:** O(2ⁿ)
**Memoized Complexity:** O(n)

Demonstrates repeated subproblems and efficiency improvement.

---

## 🔹 Experiment 5 – Tower of Hanoi

* Recursive implementation
* Printed full move sequence for N=3
* Move count verified for N=4

**Moves Formula:** 2ⁿ − 1
**Time Complexity:** O(2ⁿ)

---

## 🔹 Experiment 6 – Recursive Binary Search

* Recursive implementation
* Handles not-found and empty cases

**Recurrence Relation:**
T(n) = T(n/2) + O(1)

**Time Complexity:** O(log n)
